# 考勤记 (Checkin Diary)

一款纯前端、数据 100% 本地化存储的考勤与加班统计工具。无需任何后端服务，支持移动端左右手势滑动切月，内置中国法定节假日/调休离线识别引擎、弹性工时与用餐扣除精确算法、批量 Excel 导入导出及 ECharts 可视化趋势图表。

---

## ✨ 核心特性

1. **纯前端 & 100% 本地化存储**：
   - 零服务端依赖，基于 `LocalStorage` 进行数据持久化，数据绝不上传第三方服务器，安全私密。
   - 支持全量数据以 JSON 格式一键备份与恢复，支持导出全量考勤报表为 Excel。

2. **移动端手势日历**：
   - 移动端支持流畅的**左右触摸滑动（Touch Swipe）**切换月份。
   - 桌面端与移动端自适应（移动端沉浸式底部 TabBar，桌面端优雅顶栏）。

3. **智能节假日与调休识别引擎**：
   - 内置中国法定节假日与国务院调休补班数据字典（覆盖 2023 - 2026+ 年）。
   - 自动识别法定假期（休）与调休补班工作日（班）。
   - 允许用户在日历上针对特定日期自定义覆盖节假日属性。

4. **高精度工时与加班扣减引擎**：
   - 可配置上班时段（如 `09:00 - 18:00`），工作日早到不计加班，下班后开始计加班。
   - 周末/节假日出勤支持全额计为加班。
   - 支持次日跨天界定（如凌晨 06:00 前下班仍算作前一天晚间加班）。
   - **用餐时间扣减**：支持配置多个用餐时段数组（如午餐、晚餐），精确计算**交集重叠时长**扣除，未落在加班内的用餐时间自动忽略。
   - **取整策略**：支持向下取整到整小时（默认）、按半小时（0.5h）向下取整、不取整（保留两位小数）。

5. **考勤状态色彩区分**：
   - 清晰色彩区分：正常出勤、缺勤（旷工/历史工作日未打卡）、请假、调休、法定假日。

6. **Excel 批量导入导出**：
   - 提供标准 Excel 模版下载。
   - 智能识别表头列名，兼容钉钉、企业微信等考勤报表。
   - 导入前提供数据预览与覆盖提醒。

7. **统计分析与 ECharts 图表**：
   - 核心 KPI：累计加班工时、缺勤天数、请假天数、调休天数、正常出勤天数。
   - **月度明细**：呈现当月「每日加班时长折线图」与平均线。
   - **年度趋势**：呈现 1~12 月「每月加班时长折线/柱状图」与峰值标注。

8. **UI 与深色模式**：
   - 采用现代化设计语言，无 emoji，全站使用 SVG 矢量图标（Lucide）。
   - 支持浅色、深色及跟随系统的主题无缝切换。

## 🚀 快速启动与开发

### 1. 启动本地开发服务器
```bash
npm run dev
```
打开浏览器访问显示的本地地址（通常为 `http://localhost:5173`）。

### 2. 生产环境构建
```bash
npm run build
```
构建产物将输出至 `dist/` 目录，可直接部署在任意静态托管（GitHub Pages、Vercel、Cloudflare Pages、Nginx 或直接静态访问）。

### 3. 本地预览构建产物
```bash
npm run preview
```
